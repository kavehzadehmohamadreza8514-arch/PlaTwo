# PlaTwo - Board Games Platform

پروژه پایانی درس برنامه‌سازی پیشرفته (Advanced Programming)

## معرفی پروژه
پلتفرم **PlaTwo** یک مجموعه بازی تخته‌ای (Board Game) چندنفره است که با زبان **C++** و فریم‌ورک **Qt** توسعه یافته است. در این پلتفرم، کاربران می‌توانند حساب کاربری ایجاد کنند، وارد سیستم شوند و در محیطی بر پایه معماری کلاینت-سرور (Client-Server) به رقابت با یکدیگر بپردازند. 

این سیستم از سه بازی کلاسیک زیر پشتیبانی می‌کند:
1. **Dots and Boxes** (نقطه‌بازی با قابلیت انتخاب رنگ‌های متمایز و تشخیص خودکار تکمیل مربع)
2. **Nine Men's Morris** (دوز دوازده‌تایی با پیاده‌سازی کامل قوانین Mill و حرکت مهره‌ها)
3. **Fanorona** (فانورونا با پشتیبانی از قابلیت Capture زنجیره‌ای)

## ویژگی‌های کلیدی
* **سیستم احراز هویت (Authentication):** ثبت‌نام و ورود کاربران با پسوردهای هش‌شده (Hashed)، اعتبارسنجی ایمیل/شماره تلفن، و قابلیت تغییر رمز عبور.
* **ارتباطات شبکه:** پیاده‌سازی با استفاده از Qt Sockets. امکان ایجاد اتاق توسط میزبان (تعیین محدودیت زمانی، پورت و تنظیمات زمین) و اتصال مهمان از طریق IP.
* **مدیریت منطق بازی (Game Logic):** اعتبارسنجی لحظه‌ای حرکات مجاز (Valid Moves)، اجرای تایمر اختصاصی برای نوبت‌ها، و تشخیص خودکار برنده یا بازنده در صورت اتمام زمان.
* **پروفایل و تاریخچه:** نمایش هیستوری دقیق بازی‌ها (نام حریف، تاریخ، نتیجه، امتیازات) و امکان ویرایش اطلاعات کاربری.
* **بازیابی وضعیت (State Recovery):** حفظ وضعیت بازی در صورت قطع ناگهانی ارتباط یکی از بازیکنان، با قابلیت توقف و از سرگیری بازی در آینده.

## تکنولوژی‌ها و مفاهیم استفاده شده
* **زبان برنامه‌نویسی:** C++
* **فریم‌ورک:** Qt Framework
* **مفاهیم کلیدی:** OOP (شی‌گرایی)، STL، Polymorphism، Threading، و Socket Programming
